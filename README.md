# 💰 Expense Tracker

A simple and intuitive expense tracking application built with React.js that helps users manage their daily expenses and monitor their spending habits efficiently.

## 🚀 Features

* Add new expenses
* View all recorded expenses
* Delete expenses
* Real-time expense updates
* User-friendly interface
* Responsive design
* Component-based architecture using React

## 🛠 Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3

## 📂 Project Structure

```text
src
├── components
├── assets
├── App.js
└── index.js
```

## ⚡ Getting Started

### Clone Repository

```bash
git clone https://github.com/itsmohdzeeshan/Expense-Tracker.git
```

### Navigate to Project

```bash
cd Expense-Tracker
```

### Install Dependencies

```bash
npm install
```

### Run Application

```bash
npm start
```
